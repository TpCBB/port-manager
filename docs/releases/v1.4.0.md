## [1.4.0] - 2026-11-19 · 更新体验测试版

### Features · 新增功能

- macOS 和 Windows 在启动及驻留每 24 小时检查新版，也可手动检查。查看公开发布信息，不上传端口或进程数据。
- 在 macOS 侧栏、菜单栏面板或 Windows 主窗口、托盘菜单中直接下载本平台安装包，显示进度，验证大小与 SHA-256。只有校验成功才提供打开 DMG / 定位 EXE 的入口，不自动运行或替换旧程序。

### 如何测试

- **v1.3.0 没有更新入口**：首次请从本页手动下载。打开 v1.4.0 点「检查更新」；没有更高可用版本时应提示已是最新版本，不应下载自己。
- 测试完整的「发现 → 下载 → 手动安装」需要版本号低于发布版、且已经包含检查更新功能的测试客户端。桌面交互请在对应系统上验收。

### Downloads · 下载

- **macOS 13+ / Apple Silicon**：`PortManager-1.4.0-mac-arm64.dmg` 或 `PortManager.zip`。临时签名，未使用 Developer ID 签名或公证。
- **Windows x64 / .NET Framework 4.x**：`PortManager-1.4.0-win-x64.exe` 或便携 ZIP。EXE 未签名。
- 四个附件各有对应 `.sha256` 文件。校验和用于核对文件完整性，不代替平台签名。
