## [1.3.0] - 2026-11-13

### Features · 新增功能

- 新增 Windows x64 预览版：TCP / UDP 端口查看、搜索、进程路径与命令、父进程和关联 Windows 服务。
- Windows 支持请求关闭主窗口、确认后强制结束进程，以及关闭窗口后驻留系统托盘；操作前复核进程启动时间和端口归属。

### Changed · 官网与发布

- 官网改为「Agent 跑项目，端口我来管」，围绕多项目本地服务的查看、来源核对和收尾重写介绍与互动演示。
- 增加 macOS / Windows 下载入口，并说明平台差异：Windows 暂不读取工作目录，也不自动识别 Agent 会话或项目归属。
- 两个平台分别构建、自检、打包；全部成功并核验附件校验值后，才发布同一预览版。Windows EXE 文件版本统一读取 `VERSION`。

### Downloads · 下载

- **macOS DMG** — `PortManager-1.3.0-mac-arm64.dmg`，打开后拖入「应用程序」。
- **macOS ZIP** — `PortManager.zip`，解压后将「端口管家.app」移入「应用程序」。
- **Windows EXE** — `PortManager-1.3.0-win-x64.exe`，下载后直接运行。
- **Windows ZIP** — `PortManager-1.3.0-win-x64.zip`，解压后运行 `PortManager.exe`，附许可证和使用说明。
- **SHA-256** — 四个下载文件均有对应 `.sha256` 文件。

### Requirements · 系统要求与预览状态

- **macOS：** Apple Silicon Mac，macOS 13+。临时签名，未经过 Apple Developer ID 签名或公证。
- **Windows：** 64 位 Windows，需 .NET Framework 4.x，EXE 未签名。请求关闭仅对有主窗口的进程生效；无窗口开发服务通常需要确认后强制结束。IPv4 / IPv6 地址分别显示，不支持读取工作目录。
- 两版界面为简体中文，免费开源。部分进程详情受权限和进程状态影响。未提供 Intel Mac 或 Linux 包。

> 预览版。发布流程验证端口发现、搜索、身份复核与测试子进程结束；完整 Windows 桌面交互、托盘操作和 macOS 菜单栏结束进程等图形交互仍需进一步验收。如被系统拦截，请先核对 GitHub 发布来源和 SHA-256，再按系统提示处理。

<summary>English release notes</summary>

- Added a Windows x64 preview with TCP / UDP discovery, search, readable process paths and commands, parent processes, Windows service associations and a system tray.
- Confirm process termination after validating start time and port ownership. A normal close requires a process with a main window; headless servers generally need confirmed forced termination.
- Refocused the website on managing local services started across agent projects, with separate macOS and Windows downloads.
- Both platform builds and self-tests must pass before one release is published. Windows file versions read the shared VERSION file. All four downloads include SHA-256 files.

macOS requires Apple Silicon and macOS 13+, and remains ad-hoc signed without Developer ID signing or notarization. Windows requires x64 Windows and .NET Framework 4.x; the executable is unsigned. Windows does not read working directories or merge IPv4 / IPv6 rows. Neither app automatically attributes services to agent sessions or project groups. The interface is in Simplified Chinese. Full Windows desktop and tray acceptance, and complete macOS menu bar termination acceptance, are still pending.
