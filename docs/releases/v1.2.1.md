## [1.2.1] - 2026-11-11

### Changed · 展示与发布

- 重新设计中英文项目首页：居中图标、项目徽章、下载入口和主窗口 / 菜单栏组合预览。
- 整理功能、系统要求、安装、使用和源码构建说明。
- 新增标签发布流程：自动测试、构建和打包；应用版本统一读取 `VERSION`。

### Added · 下载附件

- **DMG** — `PortManager-1.2.1-mac-arm64.dmg`，打开后拖入「应用程序」。
- **ZIP** — `PortManager.zip`，解压后将「端口管家.app」移入「应用程序」。
- **SHA-256** — 两个安装文件均提供对应的 `.sha256` 校验文件。

### Requirements · 系统要求

Apple Silicon Mac，macOS 13 或更高版本。应用界面为简体中文。

> 预览版，使用临时签名，尚未经过 Apple Developer ID 签名或公证。如果 macOS 阻止打开，请先确认下载来源，再按「系统设置 → 隐私与安全性」中的提示允许打开。菜单栏结束进程等完整图形交互仍需进一步验收。
