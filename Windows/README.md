# Windows 预览版

这是使用 WinForms 实现的独立 Windows 客户端，提供 TCP / UDP 端口查看、搜索、进程详情、确认后结束进程与系统托盘。项目原有的 macOS 版本和发布流程不受影响。

## 构建和测试

需要 64 位 Windows 与 .NET Framework 4.x，使用 PowerShell 在仓库根目录运行：

```powershell
.\scripts\build-windows.ps1 -Test
.\dist\windows\PortManager.exe
```

不加 `-Test` 只编译。测试会创建临时 TCP / UDP 监听，并只结束它启动的测试子进程。构建结果为未签名的本地程序，不会安装服务或修改系统配置。

## 使用

- 搜索框支持端口、PID、进程名、路径和可读取的启动命令；下方显示父进程和关联的 Windows 服务。
- 选择进程后可请求关闭窗口，或明确确认后强制结束。结束前重新检查进程启动时间和端口归属；无法确认身份时拒绝执行。
- 关闭主窗口后程序在系统托盘继续运行；右键托盘图标可退出。
- 某些 Windows 网络环境可能报告未知 TCP 状态；这些条目标记为“状态未知”，不代表已确认处于监听状态。
- 某些受保护的进程无法读取详情或终止；确有需要时可通过管理员身份运行程序。命令行可能包含敏感参数，分享截图或日志前请检查。
- IPv4 / IPv6 地址分别显示，不读取其他进程的工作目录；Windows 预览版的界面与功能尚未完全对齐 macOS 版本。
